# Padrao de Cores - Status e Prioridade

Referencia visual: inspiracao no estilo de leitura rapida do Monday (sem copiar identidade).

## Status de tarefa
- `todo` (A fazer): `default` (cinza neutro)
- `in_progress` (Em progresso): `processing` (azul)
- `blocked` (Bloqueada): `warning` (amarelo/laranja)
- `done` (Concluida): `success` (verde)

## Prioridade de tarefa
- `low` (Baixa): `blue`
- `medium` (Media): `gold`
- `high` (Alta): `volcano`
- `critical` (Critica): `red`

## Regras de aplicacao
- Sempre mostrar texto + cor (nao depender apenas da cor para comunicar status).
- Reutilizar os mesmos mapeamentos em:
  - tabelas de tarefas,
  - cards de kanban,
  - detalhe de tarefa,
  - painel Meu trabalho.
- Evitar criar novas variantes sem atualizar este documento.
