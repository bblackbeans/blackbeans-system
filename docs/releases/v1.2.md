# BlackBeans System — Release 1.2 / 1.2.1

Alterações desta versão (modal Novidades **1.2** / patch **1.2.1**).

## Descrição e Atualizações (composer Monday)

- Editor TipTap estilo Monday: toolbar, `@`, emoji, link, checklist, clipe (imagem) e documento (anexo).
- Colar print (`Ctrl+V`) com preview imediato (`blob:`), upload em background e toast de progresso.
- Mitigação de duplicação no paste (Linux: arquivo + HTML) e limpeza determinística do compositor após **Atualizar**.
- Mutex no create/update de comentário (um POST por clique).
- Visualização publicada com **um** `<img>` nativo + Modal no zoom (sem thumbnail duplicado do Ant Image).
- Proxy multipart de upload corrige corrupção de PNG; paths `/media/...` no mesmo origin.
- Rascunho local até **Atualizar** (comentário) ou **Salvar** a tarefa (descrição).
- Markdown legado → HTML na carga; menções no HTML disparam notificação/e-mail no publish.

## Filtros

- Meu trabalho e Dashboard com o mesmo padrão **Incluir / Exceto**.
- Multi-seleção em status, prioridade, cliente, projeto (e colaborador/grupo no Dashboard).
- Em Meu trabalho, prazos também aceitam múltiplos valores com Incluir/Exceto.

## Histórico

- Títulos de cronômetro (`task.time.*`) em português.
- Status “de X para Y” com rótulos legíveis (A fazer, Em andamento, etc.).
- Campos alterados com nomes amigáveis (ex.: Horas previstas).
- Comentários no histórico mostram trecho do texto.

## Permissões

- Colaboradores autenticados podem editar **todas** as infos da tarefa (PATCH `/tasks/{id}`), com registro no histórico.
- Alteração de responsável também liberada para autenticados.

## Relatar problema

- Captura de tela inclui modais/drawers do sistema (só a UI do próprio reporte fica de fora).
- FAB de reporte permanece disponível com drawer de tarefa aberto.
- Erros JS e requisições ≥400 geram log automático em Problemas (com dedupe ~15 min).
- Layout do JSON de contexto técnico com scroll/quebra de linha (não estoura a tela).
