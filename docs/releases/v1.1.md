# BlackBeans System — Release 1.1

Documento de consolidação do que foi entregue na versão **1.1** (antes da 1.2).

## Tema e aparência

- Tema escuro como padrão para todos os usuários.
- Atributo `data-bb-theme=dark` no HTML inicial (evita flash de tema claro).
- Modal de Novidades adaptado a tema claro/escuro.

## Tarefas e listas

- Ordenação por prazo fim (mais atrasado → mais longe; sem prazo no fim).
- Status editável com pills coloridas (Meu trabalho / listagens).
- Tempo em formato `Xh Ym` (ex.: 10,75 → 10h 45m), com batch `/tasks/time-summaries`.
- Lista do projeto (modo tabela) alinhada à de Meu trabalho: colunas, timer, ações em ícone.
- Botão **Nova tarefa** disponível também para colaborador nos boards.

## Descrição, comentários e histórico

- Pré-visualização ao vivo na edição da descrição; colar imagem não fecha o editor.
- Comentários com imagem inline, menções `@` e preview.
- Campo de comentário maior e redimensionável.
- Menções em descrição/comentário disparam notificação/e-mail.
- Histórico da tarefa iniciado em português formal (primeira passagem).

## Horas e perfil

- “Esforço (pts)” renomeado/exibido como **Horas previstas**.
- Cargo editável em Dados pessoais.
- Avatar via `/media` corrigido.
- Teste de e-mail com mensagem mais clara quando SMTP falha.
- Remoção do spam de 403 em `/audit/*` (só superusuário).

## Seed de homologação

- `seed_qa_demo` expandido com mais pessoas, status e prazos variados para testes.

## Versão do modal Novidades

- Iterações sob o carimbo `2026.08.04.x` no cliente; este documento fixa o conjunto **1.1** para histórico de produto.
